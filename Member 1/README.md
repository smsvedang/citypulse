# CityPulse

Next.js App Router dashboard demo built from the CityPulse PRD.

## Run

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Demo path

- Click **Simulate scenario** to step through the rain, traffic, transit, and grounded brief flow.
- Click map zones to inspect their detail states.
- Use activity filters and acknowledge the active alert.

The demo uses synthetic data and clearly labels it in the interface. The dashboard keeps the language of event relationships non-causal: signals may be related, but causation is never asserted.
